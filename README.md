# Tarea 4 - Almacenamiento y Consultas de Datos en Big Data (MongoDB)

Repositorio con la implementación práctica individual correspondiente al curso **Big Data (202016911)** de la Universidad Nacional Abierta y a Distancia (UNAD).

## 📌 Caso de Uso: Plataforma E-commerce *MegaShop Data*
Implementación de una base de datos NoSQL documental (`ecommerce_db`) diseñada para gestionar un catálogo de productos y el registro transaccional de ventas, aprovechando la flexibilidad de esquema de MongoDB.

## 📂 Contenido del Repositorio
* **`productos_100.json`**: Conjunto de datos de prueba con 100 documentos estructurados (categorías: Tecnología, Hogar y Herramientas).
* **`consultas_mongodb.js`**: Script con las operaciones CRUD (inserción, selección, actualización, eliminación), filtros con operadores relacionales, unión entre colecciones (`$lookup`) y consultas de agregación estadística (`$group`, `$sum`, `$avg`).
* **`T4_BigData_Individual_Evidencias.pdf`**: Presentación con el diseño del esquema y las capturas de pantalla de la ejecución y resultados de cada consulta.
